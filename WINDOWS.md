# Генератор наклеек 4K — приложение для Windows

Полноценное настольное приложение для генерации и печати товарных наклеек:
штрихкоды EAN-13, тиражи, экспорт в **PDF**, **ZIP (JPG)** и прямая печать.

## Три способа запустить на Windows

### 1. Быстрый — установка как приложение из браузера (PWA)
1. Откройте приложение в **Microsoft Edge** или **Google Chrome**.
2. В тулбаре нажмите **«Скачать» → «Установить для Windows»**
   (или значок монитора в адресной строке браузера).
3. Ярлык появится в меню «Пуск», приложение работает в собственном окне и офлайн.

### 2. Запуск в окне Electron (без установки)
Самый простой путь — двойной клик по файлу **`start-windows.bat`** в корне проекта:
он сам установит зависимости, Electron, соберёт `dist/` и откроет окно.

Вручную:
```powershell
npm install
npm run build
npm i -D electron
npx electron electron/main.cjs
```
Внимание: команда `npx electron .` не сработает — в package.json нет поля `main`,
указывайте путь `electron/main.cjs` явно.

### 3. Сборка установщика .exe (NSIS)
```powershell
npm install
npm run build
npm i -D electron electron-builder
npx electron-builder --config electron-builder.yml --win
```
Установщик появится в папке `release/` (файл `Nakleyki4K-Setup-x.x.x.exe`),
с ярлыками на рабочем столе и в меню «Пуск».

## Если окно Electron пустое (диагностика)

Симптом: окно открывается, но внутри ничего не отображается.

**Причина №1 — запуск без сборки.** Папки `dist/` нет или она устарела.
Решение: выполните `npm run build` (или просто запустите `start-windows.bat`).

**Причина №2 — страница открыта через `file://`.** Сборка Vite ссылается на
скрипты по абсолютным путям (`/assets/...`), а протокол `file://` ищет их в корне
диска — скрипты не находятся, окно пустое. В `electron/main.cjs` уже встроен
локальный HTTP-сервер, который раздаёт `dist/` на `http://127.0.0.1` — поэтому
запускайте именно через него (`npx electron electron/main.cjs`), а не открывайте
`dist/index.html` двойным кликом в проводнике.

**Причина №3 — не установлены зависимости.** Выполните `npm install` и
`npm i -D electron` в папке проекта.

Для отладки в окне приложения нажмите **Ctrl+Shift+I** — откроются инструменты
разработчика, вкладка Console покажет точную ошибку.

Иконка окна: Windows принимает только `.ico`/`.png` — положите файл
`build/icon.ico`, и он подхватится автоматически (SVG поддерживается только
в Linux/macOS).

## Возможности

### Модуль «Проверка списков» (вкладка)
- Загрузка 2–3 списков: файлы TXT/CSV (drag&drop или кнопка) либо вставка текста.
- Проверки: одинаковое количество строк, совпадение первых номеров «1_», «2_», …
  по позициям, дубликаты строк и номеров внутри каждого списка.
- Предупреждения: строки без номера, сбои порядка нумерации, пересечения между списками.
- Отчёт: вердикт, сводные плитки, таблица расхождений по позициям, детальный список проблем.
- Кнопка «Пример» загружает демо-списки с типовыми ошибками для проверки модуля.

### Модуль «Наклейки»
- **Настройки наклейки**: свой логотип поставщика (загрузка/скрытие), размер наклейки
  (пресеты 500×850, 400×600, 600×900, 380×520 + произвольный), шрифт и кегль,
  цвет и толщина рамки, фон строки «Поставщик», «зебра», видимость и высота каждой
  ячейки, собственные графы (например, «Партия», «Срок годности»).
- **Умный текст**: длинные названия переносятся по строкам, кегль подбирается
  автоматически; «Количество» всегда в одну строку.
- **Менеджер фото и штрихкодов**: кнопка «Просмотр» у зоны загрузки открывает окно
  списка — удаление, замена каждого файла, изменение порядка (▲/▼).
- **Остановка экспорта**: кнопка «Остановить» прерывает рендер ZIP/PDF в любой момент.
- **Полноэкранный просмотр**: клик по наклейке разворачивает её на весь экран
  (масштаб, вписывание, листание ←/→, Esc).
- Многострочные поля: каждая строка = отдельная наклейка; тираж копий по строкам;
  флаги «Одинаковые» для полей Заказ / Материал / Количество.
- Автогенерация штрихкода **EAN-13** из цифр (12 цифр — контрольная добавится сама),
  либо загрузка готовых картинок штрихкодов.
- Фото товара: вертикальные снимки автоматически поворачиваются в альбом.
- Автосохранение полей и настроек в localStorage, масштаб предпросмотра,
  горячие клавиши (Ctrl+Enter — печать).
