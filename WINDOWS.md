# Генератор наклеек 4K — приложение для Windows

Полноценное настольное приложение для генерации и печати товарных наклеек:
штрихкоды EAN-13, тиражи, экспорт в **PDF**, **ZIP (JPG)**, прямая печать
и модуль «Проверка списков».

## Три способа запустить на Windows

### 1. Быстрый — установка как приложение из браузера (PWA)
1. Откройте приложение в **Microsoft Edge** или **Google Chrome**.
2. Нажмите значок **«Установить»** (монитор со стрелкой) в адресной строке.
3. Ярлык появится в меню «Пуск», приложение работает в собственном окне и офлайн
   (сервис-воркер кэширует всё при первом запуске).

### 2. Запуск в окне Electron (без установки)
Двойной клик по **`start-windows.bat`** — скрипт сам установит зависимости,
Electron, соберёт `dist/` (если его нет) и откроет окно приложения.

Вручную:
```powershell
npm install
npm run build
npm i -D electron
npx electron electron/main.cjs
```

### 3. Сборка установщика .exe (NSIS)
Двойной клик по **`make-exe.bat`** — полная автоматическая сборка.

Вручную:
```powershell
npm install
npm run build
npm i -D electron electron-builder
npx electron-builder --config electron-builder.yml --win
```
Результат в папке `release/`:
- `Nakleyki4K-1.0.0-x64.exe` — установщик (ярлыки на рабочем столе и в «Пуске»);
- `Nakleyki4K-Portable-1.0.0.exe` — portable-версия без установки.

## Если окно Electron пустое (диагностика)

**Причина №1 — запуск без сборки.** Папки `dist/` нет или она устарела.
Решение: `npm run build` (или просто запустите `start-windows.bat`).

**Причина №2 — страница открыта через `file://`.** Сборка Vite ссылается на
скрипты по абсолютным путям (`/assets/...`), а протокол `file://` ищет их в корне
диска — скрипты не находятся, окно пустое. В `electron/main.cjs` встроен
локальный HTTP-сервер, раздающий `dist/` на `http://127.0.0.1`, — поэтому
запускайте именно через него, а не открывайте `dist/index.html` в проводнике.

**Причина №3 — не установлены зависимости.** `npm install` и `npm i -D electron`.

Для отладки в окне приложения нажмите **Ctrl+Shift+I** — вкладка Console
покажет точную ошибку.

## Возможности
- **Настройки наклейки**: свой логотип поставщика (загрузка/скрытие), размер в мм
  (пресеты 50×85, 40×60, 60×90, 38×52 + произвольный), шрифт и кегль,
  цвет и толщина рамки, фон строки «Поставщик», «зебра», видимость и высота каждой
  ячейки, собственные графы (например, «Партия», «Срок годности»).
- **Умный текст**: длинные названия переносятся по строкам, кегль подбирается
  автоматически; «Количество» всегда в одну строку.
- **Менеджер фото и штрихкодов**: кнопка «Просмотр» у зоны загрузки открывает окно
  списка — удаление, замена каждого файла, изменение порядка (▲/▼).
- **Остановка экспорта**: кнопка «Остановить» прерывает рендер ZIP/PDF в любой момент.
- **Полноэкранный просмотр**: клик по наклейке разворачивает её на весь экран
  (масштаб, вписывание, листание ←/→, Esc).
- **Проверка списков**: 2–3 списка (TXT/CSV или вставка), сверка количества строк,
  первых номеров «1_», «2_», …, поиск дубликатов, развёрнутый отчёт.
- Многострочные поля: каждая строка = отдельная наклейка; тираж копий по строкам;
  флаги «Одинаковые» для полей Заказ / Материал / Количество.
- Автогенерация штрихкода **EAN-13** из цифр (12 цифр — контрольная добавится сама),
  либо загрузка готовых картинок штрихкодов.
- Фото товара: вертикальные снимки автоматически поворачиваются в альбом.
- Автосохранение полей и настроек в localStorage, масштаб предпросмотра,
  горячие клавиши (Ctrl+Enter — печать).
